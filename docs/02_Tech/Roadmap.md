# 개발 로드맵

원칙: **기능을 먼저 완성하고, 질문지는 마지막에 한 번에 작성한다.** 그 전까지는 테스트용 질문 몇 개로 돌린다.

## M0. 정리 (반나절)
- [x] 스택 정리: 질문 결과를 현재 페이즈의 스택(전구/열쇠)으로 연결, 메인 문을 페이즈 전환에 연결 ([ImplementationStatus 버그 1](ImplementationStatus.md))
- [ ] 에디터: 메인 방 문 `DoorType`을 `MainDoor`로 설정
- [ ] 체력 클램프 버그 (`Clamp(0, 100)` → `GetMaxHealth()`), 플레이어 체력 시작값 50 복구
- [ ] 네이티브 게임플레이 태그 파일 추가

## M1. 선택지 효과 시스템 (핵심)
- [ ] 선택지 → 결과(가중치) → 효과 목록 데이터 구조 (GDD 7.2)
- [ ] 효과 실행기: 스택, 체력, 정신력, 즉사, 버프(GE), 몬스터 소환, 아이템 지급, 지속 효과, 환경 변화
- [ ] 메인 방 천장 스폰구·투하구 액터
- [ ] 선택지 문구 자동 생성 (효과 데이터 → "체력 10 회복")
- [ ] 테스트용 질문 JSON 10개 (원안 예시 6개 + 무의미 2개 + 확률 2개)
- [ ] 치트 커맨드 (`AddStack`, `SetSanity`, `SpawnMonster`, `GiveItem`, `GotoPhase`)
