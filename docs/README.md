## 문서 관리 규칙
- 모든 기획·설계 문서는 이 `docs/` 폴더에서 Markdown으로 관리한다.
- 결정된 사항은 GDD에 반영하고, 논의 중인 사항은 문서 안에 `> 논의 필요` 표시로 남긴다.
- 원본 초기 기획(노션)은 참고용으로만 두고, 이후 변경은 여기서 한다.
